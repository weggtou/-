快速求一维数组某个区间和或多维数组某个区间的和的方法

1.创建一个新的数组，新数组的第i个元素记录了旧数组前i个元素的和
int a[n],b[n];
int sum = 0;
for(int i = 0;i<n;i++){
  sum += a[i];
  b[i] = sum;
}
这样数组b第i位就是数组a的前i位和了
如果要计算a[L,N]的元素之和就可以用b[N]-b[L-1],加上求b的过程复杂度仅有
O(n)+O(1);

2.代码优化
将sum值去掉代码可以更简洁
int a[n],b[n];

for(int i = 0;i<n;i++){
  b[i] = b[i-1]+a[i];
}
但是此时的第一位需要额外考虑
for(int i =0;i<n;i++){
  if(i) b[i] = b[i-1];
  b[i] +=a[i];
}

3.在c++中有专门干这个的函数
#include <numeric>
partial_sum(a.begin(),a.end(),b.begin());
a,b对应上文

4.特殊情况,当要取的范围中L为0时，b[L-1]会越界，
对于这种情况有两种解决办法，
(1)对L进行判断
if(L==0)return b[N]
else return b[N]-b[L-1]

(2)或者直接将b整体向前移动一位，使得L最小值取1，则L-1最小值一定是0
a[x] b[x+1]
正常输入a
partial_sum(a.begin(),a.end(),b.begin()+1);

5.前缀和变种，所有有逆运算且有结合律的运算都可以这么干
(1)乘法，太难了看不懂
(2)^异或
异或的逆运算就是自身
L,N = b[N]^b[L-1]

例外我们可以发现，在一段距离之和如果异或和相同，说明这段的异或和为0
证明
a^b^c^d = a
a^0 = a
因为满足结合律
b^c^d = 0
当然要注意在开始时值为0，所以在b数组中为0的是从开头到该位置异或和为0
知道有多少个相同的数就可以同过排列组合计算出有多少段数异或和为0了

6.不是加也可以使用partial_sum，
和stl容器类似，最后一个位置接受一个操作函数，输入两个值，一个是b[i-1]一个是a[i]
以异或举例
partial_sum(a.begin(),a.end(),b.begin(),[](int a,int b){
  return a^b;
})
不用写特殊情况的处理，partial会自己处理

7.对二维矩阵
要先对每一行求前缀和再对每一列求前缀和
这样前缀和数组中每个位置的值为以该位置为右下角的矩阵值的和(图片)
求某个子矩阵的前缀和就是用右下角的前缀和减去左下角的前缀和减去有上角的前缀和加上左上角的前缀和(图片)

for(int i =1;i<=n;i++){
  for(int j =1;j<=m;j++){
    int x;
    cin >> x;
    sum[i][j] = x+sum[i-1][j] + sum[i][j-1]-sum[i-1][j-1]
  }
}
8.前缀和不光可以用来求区间运算，对于需要多次查询从起点到目标位置的运算值时也可以用
前缀和来简化

9.后缀和
partial_sum(a.rbegin(),a.rend(),b.rbegin())
可以求后缀和，就是前缀和反过来，从后1个数的和求到后i个数的和
注意b也是反着存的，b从后往前的第i个位置，为a从后往前i个元素的和

使用场景
如要求一个数组从后往前的和，如果遇到0就再从0开始
partial_sum(a.rbegin(),a.rend(),b.rbegin(),[](int a,int b){
  if(a)return a+b;
  return a;
})
如果遇到0则b数组该位置的值会变为0，之后的数求后缀和时就还要从0开始了
