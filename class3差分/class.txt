差分是前缀和的逆运算，用于快速处理一个区间的操作

1.差分就是记录该位置与前一个位置差的数组
d[i] = a[i]-a[i-1]
如果是直接覆盖原数组需要从前往后遍历防止前面的值减错
for(int i = n-1;i>=0;i--){
  if(i)a[i] = a[i]-a[i-1];
}
如果是新建数组来存储就无所谓了
for(int i = 0;i<n;i++){
  if(i==0)d[i] = a[i];
  else d[i] = a[i] - a[i-1];
}

同样，也有函数来专门干这个
adjacent_difference(a.begin(),a.end(),d.begin());

2.对原数组L到R的元素都加k==对差分数组L的位置加k,R+1的位置减k，再求前缀和;

3.二维差分，不用理解，就是二维前缀和反过来
因为前缀和是先计算每行的前缀和再计算每列的前缀和，所以反过来
先计算每一列的差分，再计算每一行的差分
auto d = vector(n+1,vector<int> m+1);
for(int i = n;i>=1;i--){
  for(int j = m;j>=1;j--){
    d[i][j] = d[i][j]-d[i-1][j];
  }
  adjacent_difference(d[i].begin(),d[i].end(),d[i].begin());
}
或
因为前缀和是a[i][j]+a[i-1][j]+a[i][j-1]-a[i-1][j-1]
所以差分是a[i][j]-a[i-1][j]-a[i][j-1]+a[i-1][j-1]
for(int i = n;i>=1;i--){
  for(int j = n;j>=1;j++){
    d[i][j] = d[i][j] - d[i-1][j] -d[i][j-1] +d[i-1][j-1];
  }
}

4.同样如果想要对二维数组一个范围内进行加k的操作
如a[i][j]到a[l][r]
那么只需要在差分数组中a[i][j],a[l+1][r+1]的位置加k,a[l+1][j],a[i][r+1]的位置减k即可
具体怎么推出来的想一想二维前缀和公式便知

5.对于区间进行可逆的运算也都可以用差分进行简便的求解
如异或运算等

6.一些有规律的累加也适用于差分
例如一个等差数列
a0 a0+d a0+2d a0+3d 0 0 0
取差分
a0 d d d -(a0+3d) 0 0
再取差分
a0 d-a0 0 0 -a0-4d a0+3d 0;
可以发现
如果想要得到等差数列的n个值，知道a0和d
只需要创建一个n的空数组让第一个值为a0，第二个值为d-a0求两次前缀和即可
注：为什么最后的两个值也要存在呢，是因为如果是对一个区域进行操作时，防止把影响传到后面需要加这两个值，在我们自己找规律时也要注意
范围外的值的变化
所有有规律的求和，让元素一直进行差分就能找到其中的规律，不需要特别记住

7.如果差分数组除了第一个元素都是负的 那么原数组严格递减
                          正              递增
                          0              不变
